# Tietoverkosto Jamien Teema-

Satunnainen teema-arvonta jam -tapahtumaan.

## Käyttö

```bash
npm install
npm run dev
```

Tuotantoversio: `npm run build` → `dist/index.html` (yksi tiedosto, helppo hostata).

## Teemat

Muokkaa listaa tiedostossa `src/themes.ts`.

## Pikavalinnat

| Näppäin | Toiminto |
|---------|----------|
| Välilyönti | Pyöräytä |
| H | Näytä kaikki teemat |
| Esc | Sulje teemalista / aloita alusta |
